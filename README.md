# Emdad Store — Interactive UI Prototype

Interactive mobile-first prototype of the digital storefront for **Emdad Smart Modern Advertising** (alimdadat.sa).

- Single self-contained `index.html` (HTML + compiled Tailwind CSS + vanilla JS, images inlined).
- Arabic / RTL, Tajawal font.
- Live preview: https://banhameedh.github.io/emdad-store/

Demo data (products, hours, loyalty rules, rating) is placeholder content for client review.
